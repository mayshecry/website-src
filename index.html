hi, i'm mayshecry. i'm an 18 year old low-level systems developer from the netherlands. i do compilers, operating systems, and performance work that nobody asked me to do.

i've been self taught since 2019. started out like everyone else, curious and clueless, but i skipped past the web stuff pretty fast. the closer to the metal something was, the more interesting it got. now i spend most of my time thinking about kernels, syscalls, allocators, and why your code is slow.

my stack is mostly C++ / C / Rust / Go. not because they're trendy, but because they're the ones that let you actually control what the machine does. C is my beloved. i don't do frameworks, i don't do electron apps, and i definitely don't do standup meetings.

i've also got some serious networking knowledge, mostly because i used to be a redteamer. breaking into things teaches you a lot about how they work. but these days i just find low-level shit more interesting. building the machine beats breaking into it.
